# 12장 발표 구성

이 파일은 편집 가능한 구성안이며 필수 제출물 `발표자료.pdf`를 대신하지 않는다. 이번 단계는 프로그램 기능과 문서 초안의 1차 완료이며, 제출용 슬라이드 PDF는 사용자 확인 후 후속 단계에서 작성한다. 결과 수치는 `results/`의 실제 파일에서 가져온다. 학번·이름·저장소 URL은 사용자가 확정한 값만 사용한다.

| 장 | 제목 | 담을 내용 | 시각 자료 | 예정 시간 |
|---|---|---|---|---|
| 1 | 수치 미분·적분 기반 PID 최적화 | 주제, 작성 필요인 학번·이름 | 최소한의 표지 | 00:00~00:15 |
| 2 | 수동 튜닝의 비교 문제 | 응답 속도·오버슈트·잔류 오차를 함께 비교할 필요 | 실제 수동/최적 응답 그래프 예고 | 00:15~00:40 |
| 3 | 3강 적분·미분의 적용 | PID 식, 사다리꼴 누적 적분, 필터 차분, 목적함수 적분 | 수식과 해당 코드 위치 | 00:40~01:10 |

그래프에는 시간 단위 s, 출력의 정규화 단위, 선별 범례를 포함한다. 목적함수 수치를 서로 다른 단위 간 절대 비교하지 않는다. 기본 결과를 다른 플랜트나 설정에 일반화하지 않는다. 페이지 수는 전체 12장으로 구성한다.

슬라이드 3은 최종 소스와 직접 대조한다. 슬라이드 8~10의 본문 수치와 대본은 같은 결과 파일에서 가져오고, MATLAB을 실제로 실행하지 못했다면 검증 완료라고 쓰지 않는다.

## 슬라이드 8에 사용할 실제 기본 실험

출처: `results/benchmark/summary.json`, `results/benchmark/optimization.json`. dt 0.01s, 관측 30s, 목표 1, 지연 0.1s, seed 42, 평가 예산 180. 약 7.90초의 탐색 시간은 이 PC의 이번 실행값이며 일반적인 실행시간 보장이 아니다.

| 지표 | 수동 기준 | ITAE 탐색 후 |
|---|---:|---:|
| ITAE | 57.998252 | 5.159325 |
| ISE | 3.920451 | 1.931163 |
| 오버슈트 (%) | 0.000 | 9.976 |
| 2% 정착시간 (s) | 30s 내 미정착 | 7.89 |
| 종료 절대 오차 | 0.0333412 | 0.000210002 |

ITAE 감소율은 91.1043%이다. 최종 이득은 Kp=0.0482613, Ki=0.187260, Kd=0.0000399051, 미분 필터 시간상수 0.05s이다. 미분 이득이 거의 0인 PI에 가까운 해다. 지정한 범위·예산에서 찾은 값이며 전역 최적이라고 주장하지 않는다. 오버슈트와 제어입력 에너지는 증가했으므로 모든 지표가 개선되었다고 쓰지 않는다.

## 슬라이드 9에 사용할 실제 사례

- `results/benchmark/sampling_metrics.json`: dt=0.02, 0.01, 0.005s에서 ITAE=5.157860, 5.159325, 5.161675. dt는 적분 정밀도뿐 아니라 제어기의 주기를 바꾼다. 지연은 세 조건에서 모두 정확히 0.1s이다.
- `results/benchmark/failure_case.json`: Kp=80, Ki=60, Kd=0일 때 이산 폐루프의 spectral radius=1.039898>1. 이 경우 지표를 정상 수치로 보고하지 않는다.

## 슬라이드 10에 사용할 실제 독립 검증

`results/benchmark/matlab/matlab_comparison.json`의 실행 환경은 MATLAB R2026b Update 1이다. 기본 MATLAB에서 전달함수의 제어가능 표준형을 직접 구성하고 증강 행렬의 `expm`으로 ZOH를 계산했다. Control System Toolbox를 사용하지 않은 실제 검증이다.

- 최대 출력 절대 차이: 4.4408920985e-15
- 최대 제어입력 절대 차이: 8.8817841970e-16
- 허용값: 1e-7, 실제 판정 통과
- 비교 범위: 동일한 dt, 지연, PID 갱신 순서의 이산 폐루프 계산. 실물 모델 검증과 구분한다.
