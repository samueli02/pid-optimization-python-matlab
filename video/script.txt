소프트웨어랩 Term Project 발표 대본
주제: 수치 미분·적분으로 구현한 Python PID 최적화와 MATLAB 독립 검증
상태: 녹화 전 대본. 기본 실험 수치는 실제 실행 결과를 반영했습니다. 발표영상은 아직 제작하지 않았습니다.
목표 길이: 약 5분. 아래 시간은 편집 계획이며 실제 녹화 길이가 아닙니다.
대괄호의 화면 지시문은 읽지 않습니다. 최종 영상에서 말한 내용과 이 대본을 일치시킵니다.

[슬라이드 1 / 00:00~00:15 / 주제]
안녕하세요. 이번 프로젝트는 수치 미분과 적분을 이용한 PID 최적화 프로그램입니다. Python에서 제어 응답과 PID 값을 계산하고, 그 결과를 MATLAB에서 독립적으로 검증하는 구조입니다.

[슬라이드 2 / 00:15~00:40 / 문제와 목표]
PID 값을 수동으로 바꾸다 보면 응답은 빨라졌지만 오버슈트가 커지는 경우가 있습니다. 이때 어느 값이 더 좋은지 감으로 판단하기 어렵습니다. 그래서 같은 조건의 응답을 겹쳐 보고, 오차를 하나의 숫자로 계산해 비교하도록 만들었습니다. 실제 장치를 대신하는 학습용 시뮬레이터입니다.

[슬라이드 3 / 00:40~01:10 / 3강 적분·미분의 실제 사용]
핵심 연계 강의는 3강 적분과 미분입니다. 비례항은 현재 오차에, 적분항은 누적된 오차에 반응합니다. 미분항은 오차의 변화 속도를 반영합니다. 프로그램에서는 적분을 사다리꼴 규칙으로 누적하고, 미분을 이전 샘플과의 차이로 계산합니다. 미분에는 필터를 적용했습니다. 목적함수 역시 시간에 따른 오차를 수치 적분해서 구합니다.

[슬라이드 4 / 01:10~01:35 / 모델과 가정]
기본 시스템은 세 개의 일차 요소와 하나의 이차 요소, 그리고 시간지연으로 구성했습니다. 직접 정한 학습용 모델입니다. 전달함수의 계수와 감쇠, 지연을 바꿀 수 있습니다. 지연은 샘플 간격의 정수배로 구현하므로 요청한 지연과 실제 적용한 지연을 함께 확인해야 합니다.

[슬라이드 5 / 01:35~02:00 / Python과 MATLAB의 역할]
Python이 수동 PID의 응답을 계산한 다음, 정한 범위 안에서 세 이득을 탐색합니다. MATLAB에는 확정된 이득과 모델, 샘플 간격 등 설정을 전달합니다. MATLAB이 별도로 계산한 응답과 Python 응답을 비교합니다. 따라서 MATLAB을 실행하지 않아도 Python에서 조절과 최적화를 수행할 수 있습니다.

[슬라이드 6 / 02:00~02:25 / 목적함수와 지표]
ITAE는 오차의 절댓값에 시간을 곱해 적분하므로 늦게 남는 오차를 크게 반영합니다. ISE는 오차를 제곱해 적분하므로 큰 오차에 민감합니다. 어떤 목적함수를 선택했는지에 따라 좋은 PID 값도 달라질 수 있습니다. 그래서 오버슈트와 정착시간도 함께 보고, 모든 지표가 동시에 좋아졌다고 단정하지 않습니다.

[슬라이드 7 / 02:25~03:05 / 실제 실행 데모 40초]
[02:25~02:35: 실제 프로그램 창에서 Kp 슬라이더와 숫자 입력을 조절한다. 목표값과 출력 그래프를 보여준다.]
현재 화면에서 비례 이득을 바꾸면 출력과 성능 지표가 함께 바뀝니다. 다른 이득도 같은 방법으로 조절할 수 있습니다.
[02:35~02:45: ITAE를 선택하고 탐색 범위와 예산을 보여준다. 자동 최적화 버튼을 누른다.]
목적함수를 ITAE로 선택하고 자동 최적화를 실행하겠습니다. 범위와 탐색 예산은 여기에서 지정합니다.
[02:45~02:55: 실제 계산 진행을 녹화한다. 실행이 길면 완료된 다음 구간으로 편집하되 탐색 시작과 결과를 모두 보여준다.]
[02:55~03:05: 수동·자동 겹침 그래프와 결과 저장 버튼을 보여준다. 실제 결과 파일을 확인한다.]
계산이 끝나면 수동 결과와 최적화 결과를 같은 그래프에서 비교할 수 있습니다. 이득과 설정, 응답 데이터도 파일로 저장합니다.

[슬라이드 8 / 03:05~03:35 / 기본 비교 결과]
[results/benchmark/summary.json과 같은 조건의 표·그래프를 보여준다.]
기본 실험에서 ITAE는 약 58에서 5.16으로 줄어, 수동 기준 대비 91.10퍼센트 감소했습니다. 30초 안에 정착하지 못했던 응답은 7.89초에 정착했습니다. 반면 오버슈트는 0에서 약 9.98퍼센트로 커졌습니다. 찾은 미분 이득은 거의 0이어서 PI에 가까운 해입니다. 모든 성능이 동시에 좋아진 결과는 아닙니다.

[슬라이드 9 / 03:35~04:00 / 조건 변화와 실패 사례]
[sampling_convergence.png와 failure_case.json의 실제 결과를 사용한다.]
샘플 간격을 0.02초에서 0.005초까지 바꾸었을 때 ITAE는 약 5.16 근처였습니다. 다만 샘플 간격이 바뀌면 제어기 자체의 계산 주기도 달라집니다. 비례 이득 80, 적분 이득 60인 실패 사례에서는 폐루프 고유값의 최대 크기가 1을 넘어 불안정으로 판정했습니다.

[슬라이드 10 / 04:00~04:20 / 독립 검증]
[results/benchmark/matlab/matlab_comparison.json의 실제 검증 수치를 보여준다.]
MATLAB에서는 전달함수를 제어가능 표준형으로 직접 만들고, 행렬 지수함수로 이산화했습니다. 최대 출력 차이는 약 4.44 곱하기 10의 마이너스 15승으로, 허용값 10의 마이너스 7승을 통과했습니다. 이는 구현의 일치 검사이며 실제 장치를 검증한 결과는 아닙니다.

[슬라이드 11 / 04:20~04:45 / 한계와 개선]
이번 범위는 선형 모델과 계단 목표값을 중심으로 합니다. 실제 구동기의 포화나 측정 잡음, 외란까지 검증한 결과는 아닙니다. 또 제한된 범위와 탐색 예산으로 얻은 값이므로 전역 최적성을 보장하지 않습니다. 다음 단계로 포화와 anti-windup을 추가하고, 여러 조건에서 함께 좋은 이득을 찾을 수 있습니다.

[슬라이드 12 / 04:45~05:00 / 결론]
이 프로젝트에서는 미분과 적분을 실제 PID 계산과 성능 평가에 연결했습니다. 같은 조건에서 수동 조절과 자동 탐색을 비교하고, MATLAB으로 계산을 확인하도록 구성했습니다. AI가 작성한 초안은 수식과 실행 결과를 대조해 검증했습니다. 감사합니다.

녹화 전 점검
1. 실제 실행 데모를 최소 30초 이상 포함합니다. 위 계획은 40초입니다.
2. 슬라이드 8~10은 최신 결과와 실제 MATLAB 검증 수치를 반영합니다.
3. 화면 지시문이나 미확정 문장을 발화하지 않습니다.
4. 영상 전체를 재생하고 4~6분인지 확인합니다. 필요하면 문장과 쉬는 시간을 조정합니다.
5. 최종 영상에서 달리 말한 부분은 이 대본에도 그대로 반영합니다.
