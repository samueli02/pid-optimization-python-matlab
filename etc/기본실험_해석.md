# 기본 실험 해석

2026-11-11 실행 파일을 근거로 작성했다. 값은 `results/benchmark/summary.json`, `optimization.json`, `sampling_metrics.json`, `failure_case.json`에서 확인했다. 원본 파일의 값과 표시용 반올림 값은 구별한다.

## 조건

직접 정의한 5차 플랜트, 지연 0.1s, 목표값 1, dt 0.01s, 관측 30s를 사용했다. 기준 PID는 Kp=0.1, Ki=0.05, Kd=0.02이며 미분 필터 시간상수는 0.05s다. 탐색은 seed=42, 평가 예산=180으로 수행했다. 알고리즘은 경계를 둔 다중 시작점 Nelder-Mead이고 원래 제어기 후보도 유지한다.

## 실제 측정값

| 지표 | 기준 PID | ITAE 탐색 후 | 해석 |
|---|---:|---:|---|
| ITAE | 57.998252 | 5.159325 | 기준 대비 91.1043% 감소 |
| ISE | 3.920451 | 1.931163 | 이번 실험에서는 함께 감소 |
| 오버슈트 | 0% | 9.976432% | 증가했으므로 상충관계가 존재 |
| 2% 정착시간 | 30s 내 미정착 | 7.89s | 관측 구간 내 정의에 따른 결과 |
| 마지막 샘플 절대 오차 | 0.033341229 | 0.000210002 | 무한 시간의 오차라고 주장하지 않음 |
| 제어입력 최대 절댓값 | 0.391366 | 0.433485 | 제어입력 크기가 증가 |
| 제어입력 제곱 적분 | 3.184378 | 4.696663 | 비용함수에 입력 에너지를 포함하지 않은 영향 |

찾은 이득은 Kp=0.0482613258, Ki=0.1872599878, Kd=0.0000399051이다. 미분 이득이 매우 작으므로 이 모델과 목적함수에서는 PI에 가까운 해를 찾았다고 해석한다. 일반적으로 미분항이 불필요하다는 결론을 내릴 수는 없다. 전역 최적성을 증명하지 않았다.

목표로 둔 기본 ITAE 10% 이상 감소는 이 조건에서 충족했다. 오버슈트 및 입력 에너지의 증가는 별도 한계로 보고한다. 오버슈트 상한이나 입력 에너지 패널티를 목적함수에 추가하면 결과가 달라질 수 있지만, 그 효과는 아직 측정한 결과가 아니다.

## 실패 사례

Kp=80, Ki=60, Kd=0인 경우 이산 폐루프 행렬의 고유값 최대 크기는 1.039898이다. 1보다 커서 불안정으로 판정했다. 이 경우 ITAE·ISE·정착시간을 정상 지표처럼 표시하지 않으며, 큰 벌점은 탐색용 값으로만 사용한다.

## 독립 검증 결과

`results/benchmark/matlab/matlab_comparison.json`으로 실제 실행을 확인했다. MATLAB 버전은 `26.2.0.3433840 (R2026b) Update 1`이다. 이번 환경에서는 `tf` 경로를 사용할 수 없어 기본 MATLAB의 제어가능 표준형과 증강 행렬의 `expm`으로 ZOH 상태전이 행렬을 계산했다. Python 상태행렬을 가져오지 않고 전달함수 계수에서 재구성했다. Control System Toolbox 없이 실행했다.
