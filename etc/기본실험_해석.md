# 기본 실험 해석: ML 결과와 이전 수치 탐색 구분

## 현재 기본 방식: GP 머신러닝

2026-11-11의 `results/ml_benchmark/summary.json`과 `matlab/matlab_comparison.json`을 근거로 한다. 기본 모델·seed 42·총 예산 180에서 ML 선택의 ITAE는 57.998252 → 5.454838로 **90.5948% 감소**했다. 이득은 Kp=0.0432670181, Ki=0.1864916375, Kd=0.0109795611이다. 오버슈트는 0 → 11.0074%, 정착시간은 30초 내 미정착 → 9.96초였다.

학습·탐색 평가 156개와 별도 국소 검증 24개를 사용했다. 비용 GP는 안정·유효한 학습 표본 36개, 안정성 GP는 학습 표본 156개로 학습했다. 모델 추천 후보를 실제 평가한 횟수는 124회다. 홀드아웃은 마지막 모델을 동결한 뒤 최선 이득 주변에서 생성했으며 학습·후보 선택·최종 PID 선택에서 제외했다. log(1+ITAE) 기준 MAE=0.0359947, RMSE=0.0427578, R²=0.829458이다. 이 값은 국소 예측 검사이며 전체 이득 공간이나 다른 전달함수의 성능으로 일반화할 수 없다.

동일 총 예산의 Nelder-Mead 비교 비용은 5.159325로 **이번 ML 비용보다 낮다**. ML의 의미는 학습한 성능 모델로 후보를 추천하고 검증 자료를 남긴다는 데 있으며, 수치 탐색보다 항상 좋은 결과를 보장하지 않는다. ML의 예산에는 제어기 선택에서 제외한 검증 24개도 포함돼 있으므로 예산 구성도 함께 보고한다.

새 ML 설정의 MATLAB 독립 검증은 최대 출력 차이 3.3306690739e-15, 입력 차이 5.5511151231e-16으로 1e-7 허용값을 통과했다. 아래의 오래된 4.44e-15 수치는 별도 Nelder-Mead 설정의 비교 기록이다.

## 보존 기록: 이전 Nelder-Mead 실험

**이 아래 91.10% 개선과 표·MATLAB 수치는 이전 수치 탐색 결과이며 ML 학습 결과가 아니다.**

2026-11-11 실행 파일을 근거로 작성했다. 값은 `results/benchmark/summary.json`, `optimization.json`, `sampling_metrics.json`, `failure_case.json`에서 확인했다. 원본 파일의 값과 표시용 반올림 값은 구별한다.

## 조건

직접 정의한 5차 플랜트, 지연 0.1s, 목표값 1, dt 0.01s, 관측 30s를 사용했다. 기준 PID는 Kp=0.1, Ki=0.05, Kd=0.02이며 미분 필터 시간상수는 0.05s다. 탐색은 seed=42, 평가 예산=180으로 수행했다. 알고리즘은 경계를 둔 다중 시작점 Nelder-Mead이고 원래 제어기 후보도 유지한다.

찾은 이득은 Kp=0.0482613258, Ki=0.1872599878, Kd=0.0000399051이다. 미분 이득이 매우 작으므로 이 모델과 목적함수에서는 PI에 가까운 해를 찾았다고 해석한다. 일반적으로 미분항이 불필요하다는 결론을 내릴 수는 없다. 전역 최적성을 증명하지 않았다.

목표로 둔 기본 ITAE 10% 이상 감소는 이 조건에서 충족했다. 오버슈트 및 입력 에너지의 증가는 별도 한계로 보고한다. 오버슈트 상한이나 입력 에너지 패널티를 목적함수에 추가하면 결과가 달라질 수 있지만, 그 효과는 아직 측정한 결과가 아니다.
