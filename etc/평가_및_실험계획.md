# 평가와 실험 계획

2026-11-11 ML 개정. 이 문서는 평가 설계이며 목표와 실제 결과를 구분한다. 실측값은 results/ml_benchmark/summary.json과 MATLAB 비교 JSON, 이전 수치 탐색은 results/benchmark/에 기록한다.

## 문제와 강의 연계

사용자가 정한 전달함수에서 Python이 여러 PID의 응답을 시뮬레이션하고, 생성한 데이터로 GP 회귀 모델을 학습해 다음 후보를 선택한다. 최종 이득과 모델·시간 조건은 파일로 MATLAB에 전달하고 MATLAB이 응답을 독립 계산한다. MATLAB은 Python 최적화의 목적함수 안에서 실행하지 않는다.

3강 적분·미분은 PID 적분항·필터 차분·ITAE/ISE 계산에 직접 적용한다. 7강 머신러닝의 학습·예측 개념을 응용하되 GP는 프로젝트에서 선택한 확장 방법이다. 강의 원문이 없으므로 GP를 강의에서 배웠거나 특정 강의 코드를 재현했다고 주장하지 않는다.

기본 모델은 10 exp(-0.1s) / [(s+1)(0.3s+1)(0.05s+1)(s²+0.4s+4)]이다. 직접 정한 합성 모델이며 실제 장비 데이터는 사용하지 않는다.

## 계산과 데이터 흐름

- PID 적분은 사다리꼴 누적, 미분은 후진 차분과 저역통과 필터다. I0=D0=0으로 시작한다.
- 실제 시뮬레이션의 ITAE/ISE도 사다리꼴 적분으로 계산한다. 이 값이 학습 데이터의 정답이다.
- GP 비용 모델의 입력은 변환한 Kp·Ki·Kd, 목표는 안정·유효 표본의 log(1+J)다. 별도 GP가 log(스펙트럴 반지름)를 학습한다.
- GP 예측 평균·불확실성으로 기대개선을 계산해 후보를 추천한 뒤 반드시 실제 응답과 고유값을 검사한다. 안정하고 실제 비용이 낮은 후보만 채택한다.
- 커널은 고정 Matérn이며 하이퍼파라미터를 자동 조정하지 않는다. 관측값으로 GP의 사후 예측을 학습한다.
- 모델을 마지막에 동결하고 최종 이득 주변의 새로운 홀드아웃을 평가한다. 이 표본은 학습·획득함수·최종 PID 선택에서 제외한다.
- 상태공간은 ZOH 이산화하고 지연은 정수 샘플 큐로 근사한다. MATLAB도 같은 초기화와 갱신 순서를 사용한다.

## 실험 묶음과 판단 기준

| 실험 | 고정/변경 조건 | 근거와 판단 |
|---|---|---|
| A. 수동 대비 ML | 동일 모델·시간 조건, 초기 PID와 ML 선택 PID 비교 | 실제 ITAE/ISE·오버슈트·정착시간·입력 에너지. 기본 ITAE 10% 감소는 목표이며 보장이 아님 |
| B. 수치 탐색 비교 | 동일 seed·총 예산, ML과 Nelder-Mead | 총 예산 안의 학습·검증 비중을 명시. 더 나쁜 결과도 보고 |
| C. 예측 성능 | 마지막 모델 고정, 학습에 쓰지 않은 국소 표본 | log(1+J) MAE/RMSE/R²·유효 표본 수. 전체 공간의 정확도로 주장하지 않음 |
| D. 다른 전달함수 | 1차 모델로 바꾸고 새 데이터·GP 생성 | 원래 학습 결과를 재사용하지 않는지, 안정한 해를 찾는지 확인 |
| E. 조건 변화/실패 | 목적함수·지연·dt를 바꾸거나 높은 이득 사용 | 새 학습 결과를 구분. 불안정/미정착을 정상 지표로 표시하지 않음 |
| F. MATLAB 독립 계산 | 최종 ML 설정 고정 | 출력·제어입력 최대 차이 1e-7, 시간차 1e-10 미만을 검사 |

A~D와 F의 기본 실행은 src/run_ml_experiments.py 및 해당 MATLAB 검증 결과를 사용한다. E의 이전 Nelder-Mead 결과는 기존 조건 민감도 사례로만 인용하며 ML의 조건 변화 실험으로 바꿔 부르지 않는다. 목적함수별 ML 비교가 추가로 필요하면 같은 예산으로 ITAE/ISE를 각각 실행해 별도 폴더에 저장한다.

## 결과 해석

현재 기본 ML 실행에서 학습·탐색 평가 156개, 국소 검증 24개를 분리했다. 총 데이터 행 수, 비용 GP에 실제 사용한 안정 표본 수, 제약 GP의 학습 수는 서로 다른 값이다. dataset.csv의 split/phase/source와 ml_report.json을 함께 확인한다.

ITAE와 ISE는 단위·스케일이 달라 원시 값을 서로 우열 비교하지 않는다. 같은 비용의 전후 감소율을 사용한다. 불안정 기준 제어기의 벌점을 물리적 비용으로 간주해 개선율을 해석하지 않는다.

2% 정착시간은 관측 종료까지 대역을 유지한 시점이고 끝점 오차는 마지막 표본의 값이다. 유한 시간 결과를 무한시간 정상상태 보장으로 바꾸지 않는다. 제한된 예산·후보 풀, 국소 검증, 고정 커널, 합성 모델의 한계를 함께 설명한다.
