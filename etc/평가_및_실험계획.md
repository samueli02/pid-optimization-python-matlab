## 문제와 구현 범위

3강 적분·미분을 PID 제어와 성능 지표 계산에 적용한다. Python이 폐루프 시뮬레이션과 이득 탐색을 끝낸 후, MATLAB이 최종 이득과 동일한 설정으로 응답을 독립 재계산한다. MATLAB 계산을 Python 최적화 목적함수 안에서 호출하지 않는다.

기본 모델은 다음과 같은 직접 정의한 학습용 모델이다. 물리적 장치의 실측·식별 모델이 아니다.

`G(s) = 10 exp(-0.1s) / [(s+1)(0.3s+1)(0.05s+1)(s²+0.4s+4)]`

## 수치 계산 설명

- 오차: `e[k] = r[k] - y[k]`
- PID 적분항: 사다리꼴 규칙으로 누적한다. 초기 조건과 첫 샘플 처리도 코드와 발표에서 설명한다.
- 미분항: 후진 차분한 오차를 저역통과 필터로 처리한다. 이상적인 연속 미분과 유한 샘플의 차이를 설명한다.
- 목적함수: `ITAE = integral(t*abs(e))`, `ISE = integral(e**2)`를 사다리꼴 규칙으로 적분한다.
- 플랜트: 연속 상태공간을 ZOH로 이산화한다. 출력·제어입력·상태 갱신 순서를 Python과 MATLAB에서 같게 유지한다.
- MATLAB 독립 경로: 전달함수 계수에서 제어가능 표준형을 구성하고 증강 행렬의 `expm`으로 ZOH를 계산한다. Control System Toolbox가 있으면 `tf/ss/c2d` 경로도 지원하지만 이번 실제 검증은 기본 MATLAB 경로를 사용했다.
- 지연: 정수 샘플 수로 구현하고, 요청 지연과 실제 적용 지연의 차이를 표시한다.
- 안정성: 이산 폐루프 상태 전이행렬의 고유값을 검사한다. 유한 시간에 발산하지 않았다는 관찰만으로 안정하다고 판정하지 않는다.

실제 수식·알고리즘 설명은 최종 `src/pid_core.py` 및 MATLAB 코드와 일치시켜야 한다. 시뮬레이션 그래프만으로 구현 정확성을 증명할 수 없다.

## 최소 실험 묶음

| 실험 | 고정 조건 | 변경 조건 | 저장 및 해석 |
|---|---|---|---|
| A. 기준 비교 | 동일 모델, dt, 목표값, 측정시간 | 수동 PID / ITAE 최적화 PID | 응답·입력 그래프와 모든 지표, 개선율 |
| B. 목적함수 비교 | 동일 모델과 탐색 예산 | ITAE / ISE | 이득·ITAE·ISE·오버슈트·정착시간 비교, 서로 다른 우선순위 해석 |
| C. 지연 영향 | 기준 최적 PID 고정 | 지연 여러 값 | 안정성·오버슈트·정착시간 변화, 재튜닝 필요성 |
| D. 수치 해상도 | 물리 모델·PID 고정 | dt와 dt/2 | 공통 시점의 응답 차이와 지표 변화. 지연 반올림 효과도 명시 |
| E. 실패 사례 | 기준 모델 | 높은 이득 또는 큰 지연 | 불안정 판정과 그래프, 원인 및 한계 |
| F. MATLAB 검증 | Python 확정 설정과 이득 | 독립 계산 구현 | `max(abs(y_python-y_matlab))`, 목표 1e-6 이하 |

필수 보고는 A, B, C 또는 D, E, F다. MATLAB 실행이 불가능한 경우 F를 미검증으로 표시하고 실제 실행 파일은 남긴다. 미검증을 통과로 바꾸거나 추정값을 측정값으로 작성하지 않는다.

## 지표의 정의와 해석

`ITAE`는 늦게 남는 오차에 큰 가중치를 준다. `ISE`는 큰 오차를 제곱하므로 초기 큰 오차도 중요해진다. 두 수치의 단위와 스케일이 다르므로 값 자체를 서로 직접 비교하지 않고 같은 목적함수 안에서 전후를 비교한다.

2% 정착시간은 목표값을 기준으로 허용 대역에 들어간 후 관측 종료까지 유지되는 시점이다. 미정착 또는 불안정 응답에는 임의의 정착시간을 주지 않는다. 마지막 샘플의 오차나 마지막 구간 평균 오차는 유한 시간의 추정치이며 수학적 정상상태 오차와 구별한다. 오버슈트는 목표값 대비 백분율로 표시한다.

최적화 개선율은 `(J_manual-J_optimized)/J_manual*100`이다. 기준 목적함수가 0이거나 불안정하여 비교가 무의미하면 개선율을 표시하지 않는다. 전역 최적성은 증명하지 않으며, 지정한 범위·예산·시드에서 얻은 결과라고 설명한다.
